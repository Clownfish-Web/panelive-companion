Before you install

- Requires Windows 10 or 11, x64. Setup installs the Companion and required Windows
  App Runtime for your account. Run setup normally, without Run as administrator.
- Teleprompter is always included. OBS Studio, vMix, and Streamlabs Desktop adapters
  are optional; install those applications separately. Close OBS before installing,
  updating, or removing its plugin, and run OBS and Companion as the same user.
- The standard vMix build uses SRT for video and OMT for monitoring audio. Optional
  NDI integrations require a separately installed runtime under its own terms.
- Pair only trusted clients. Operator and admin clients can control production
  applications and invoke keyboard shortcuts on this computer.
- A firewall rule for local clients on private networks is selected by default.
  Only firewall changes and protected OBS plugin files request administrator
  approval when necessary. Setup and uninstall use native installer code, without
  PowerShell or command windows. Sign-in startup is optional and applies only to you.
- Setup and uninstall close Companion before changing files. An unresponsive
  Companion process is force-stopped after a short shutdown timeout.
- Uninstall preserves your profile by default. Choosing a factory reset, or using
  /PURGEIDENTITY during unattended uninstall, permanently deletes that profile,
  including its identity, paired-device credentials, and settings.
